# 🚀 Быстрый старт - Mobile Legends Community

## Запуск приложения

```bash
# Установка зависимостей
pip3 install -r requirements.txt

# Запуск приложения
python3 run.py
```

Или альтернативно:
```bash
python3 app.py
```

## 🌐 Доступ к приложению

Откройте браузер и перейдите по адресу: **http://localhost:8080**

## 🎮 Основные функции

### Для гостей:
- Просмотр героев и их характеристик
- Чтение постов сообщества
- Просмотр профилей пользователей

### Для зарегистрированных пользователей:
- Создание и редактирование постов
- Комментирование постов
- Оценка героев
- Получение достижений
- Просмотр статистики

## 🎯 Особенности системы

- **5 героев Mobile Legends** с полной информацией
- **Система рейтингов** для героев
- **Достижения** для мотивации пользователей
- **Адаптивный дизайн** для мобильных устройств
- **Современный UI** с анимациями

## 📱 Мобильная версия

Система полностью адаптирована для мобильных устройств и отлично работает на смартфонах и планшетах.

## 🔧 Настройка

Для изменения порта отредактируйте файл `app.py`:
```python
app.run(debug=True, port=8080)  # Измените порт здесь
```
