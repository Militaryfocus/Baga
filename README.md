# Mobile Legends Community System

Уникальная система фан-сообщества для игры Mobile Legends, созданная на Python с использованием Flask.

## 🎮 Особенности

- **Система пользователей** - регистрация, аутентификация, профили с уровнями и опытом
- **База героев** - подробная информация о героях Mobile Legends с навыками и статистикой
- **Система постов** - создание и обсуждение постов о героях и стратегиях
- **Комментарии** - возможность комментировать посты
- **Рейтинговая система** - оценка героев пользователями
- **Достижения** - система достижений для мотивации пользователей
- **Современный UI** - адаптивный дизайн с анимациями

## 🚀 Установка и запуск

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd mobile-legends-community
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Настройте переменные окружения:**
```bash
cp .env.example .env
# Отредактируйте .env файл
```

4. **Запустите приложение:**
```bash
python app.py
```

5. **Откройте браузер:**
```
http://localhost:5000
```

## 🎯 Функциональность

### Для пользователей:
- Регистрация и вход в систему
- Создание и редактирование профиля
- Просмотр и создание постов
- Комментирование постов
- Оценка героев
- Получение достижений

### Для администраторов:
- Управление пользователями
- Модерация контента
- Добавление новых героев
- Управление достижениями

## 🛠 Технологии

- **Backend:** Python 3.8+, Flask, SQLAlchemy
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **База данных:** SQLite (можно легко переключить на PostgreSQL/MySQL)
- **Аутентификация:** Flask-Login
- **Безопасность:** Werkzeug для хеширования паролей

## 📊 Модели данных

- **User** - пользователи системы
- **Hero** - герои Mobile Legends
- **Post** - посты пользователей
- **Comment** - комментарии к постам
- **Achievement** - достижения
- **UserAchievement** - связь пользователей и достижений
- **Rating** - оценки героев

## 🎨 Дизайн

Система использует современный адаптивный дизайн с:
- Градиентными фонами в стиле Mobile Legends

- Мобильной адаптивностью

## 🔧 Настройка

### Переменные окружения (.env):
```
SECRET_KEY=your-secret-key-here
DATABASE_URL=sqlite:///mobile_legends_community.db
```

### Для продакшена:
- Измените SECRET_KEY на случайную строку
- Настройте DATABASE_URL для вашей БД
- Используйте WSGI сервер (например, Gunicorn)

## 📝 API

Система предоставляет REST API:
- `GET /api/heroes` - список всех героев
- `GET /api/posts` - список постов
- `POST /api/like_post/<id>` - лайк поста
